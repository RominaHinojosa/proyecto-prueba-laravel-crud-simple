# 📋 Sistema de Gestión de Tareas (CRUD Laravel)

Una aplicación web interactiva para la administración de tareas desarrollada con Laravel, PHP y Tailwind CSS. El proyecto incluye gestión completa de registros, relaciones de base de datos, filtros avanzados, manejo de archivos multimedia y soporte para modo oscuro.

---

## ✨ Características Principales

* **CRUD Completo:** Creación, lectura, actualización de estado (completada/pendiente) y eliminación de tareas.
* **Relaciones de Base de Datos (1:N):** Asociación de tareas con categorías personalizadas (`Trabajo`, `Estudio`, `Personal`).
* **Prioridades con Badges:** Clasificación por niveles (`Baja`, `Media`, `Alta`) con distintivos de colores dinámicos.
* **Búsqueda y Filtros:** Filtrado en tiempo real por término de búsqueda, categoría y estado de la tarea.
* **Gestión de Archivos:** Carga y almacenamiento de archivos adjuntos (imágenes o documentos) mediante `Storage` con apertura directa.
* **Modo Oscuro (Dark Mode):** Alternancia entre tema claro y oscuro con persistencia en `localStorage`.

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** Laravel
* **Lenguaje:** PHP
* **Estilos:** Tailwind CSS
* **Base de Datos:** SQLite / MySQL
* **Entorno de Desarrollo:** Laragon / Composer
